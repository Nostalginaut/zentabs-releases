# ZenTabs downloads

A calm list of every tab open in your browsers, with gentle reminders for the ones that linger.

**[Download ZenTabs for Windows](https://github.com/Nostalginaut/zentabs-releases/releases/latest/download/ZenTabs-portable.zip)**:
unzip it and double-click `ZenTabs.exe`. No installing. *Read me first.txt* in the zip walks through the rest.

ZenTabs looks here for updates. Every release has:

- `ZenTabs-portable.zip`: the app, *Read me first.txt* and the licenses
- `ZenTabs.exe`: the app by itself, which ZenTabs downloads when it updates
- `ZenTabs.exe.sha256`: its checksum, which ZenTabs checks before installing
